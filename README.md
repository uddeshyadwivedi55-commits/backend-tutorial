# Backend Tutorial – Node.js & Express

**Developed by:** Uddeshya

## About the Project

This project is a beginner-friendly backend development project built using Node.js, Express.js and MongoDB. It demonstrates how to create a REST API and perform CRUD (Create, Read, Update and Delete) operations.

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- Postman
- Git and GitHub

## Project Features

- REST API development using Express.js.
- MongoDB database connectivity.
- User and Post management.
- Database models using Mongoose.
- Controllers for handling API requests.
- Routes for organizing API endpoints.
- Password hashing using bcrypt.
- Environment variable management using dotenv.

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/uddeshyadwivedi55-commits/backend-tutorial.git
```

2. Navigate to the project folder containing package.json.

3. Install dependencies:

```bash
npm install
```

4. Create a `.env` file and configure your MongoDB connection string and other required environment variables.

5. Start the development server:

```bash
npm run dev
```

## Testing

The API endpoints can be tested using Postman.
